## 2. 界面分析（基于视觉模型识别截图）

### 布局结构
```
左侧彩色竖向导航（单字图标）          主内容区
┌────────────┬──────────────────────────┐
│ 班 █        │  页面标题 + 操作按钮       │
│ 生 █        │  统计卡片（大数字+插画）    │
│ 座 █        │  白色大圆角内容面板        │
│ 分 █        │  （名单网格/表格/图表）     │
│ 卷 █        │                          │
│ 值 █ …      │                          │
└────────────┴──────────────────────────┘
```
导航单字对应：班(班级)/生(学生)/座(座位)/分(分数)/卷(试卷)/值(值日)/联(家校)/点(点名)/课(课程)/勤(考勤)/关(班务)/档(档案)

### 已确认模块（截图 1-6）

| 模块 | 功能 |
|------|------|
| 学生名单 | 43 人总览、男生蓝色/女生粉色卡片网格、统计卡片（总人数 43/男 22/女 21/比例 51:49） |
| 座位表 | 拖拽调座、随机排座、男女/空位区分、导出 PDF |
| 成绩分析 | 柱状图/折线图、分数段分布、前 15 名走势 |
| 成绩排名表 | 学号/姓名/性别/成绩/等级/班级排名 |
| 试卷分析 | 上传试卷 → 知识点得分率、薄弱项、教学建议 |
| 值日生/班委 | 每周值日安排、班委职责 |

### 风格特征
- **配色**：马卡龙柔和色系（粉/蓝/黄/绿/紫，低饱和）
- **组件**：大统计卡片+右下角装饰插画、白色大圆角面板、卡片式网格
- **导航**：单汉字图标 + 每项独立浅色背景 + 激活项左侧高亮条
- **整体**：柔和、轻量、教育场景亲和力强，移动端窄屏适配

## 3. 可行性评估（师座改版）

### 改法 A：只借界面风格
- 内容：马卡龙色 + 单字导航 + 大卡片统计
- 工作量：1-2 天（纯前端）
- 可行性：⭐⭐⭐⭐⭐ 高
- 保留师座现有功能（AI 场景 + 自定义任务 + BYOK）

### 改法 B：复刻数据功能
- 内容：学生花名册/座位表/成绩表/值日表（数据 CRUD + 图表）
- 工作量：2-4 周（这是此前评估过的「一体化工作台」19 模块 CRUD）
- 可行性：⭐⭐⭐ 中
- 注：workbuddy 数据是"上传 Excel 一次性加载"（localStorage，无数据库），比真数据库版轻

### 决策
**采纳方案 C（存档调研，不改版）**：
- 师座定位是「AI 场景工作台」（BYOK + pi SDK + 生成/导出），与 workbuddy 的「数据管理台」是两个产品方向
- 界面风格可参考（未来若做，优先改法 A），但当前不投入
- 师座已有能力天然衔接 workbuddy 的「成绩分析」模块（Excel 解析已支持），留作未来可选扩展
